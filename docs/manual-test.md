# 真机验证清单（0.1，M1–M5）

在 Mac 上，按顺序点一遍转录、翻译、转写、应用增强和词典。自动测试（Linux 上的 Go 测试、CI 里 macOS 上的 Swift 测试）覆盖不了这些：权限、事件 tap、真实 App 的辅助功能、浏览器、真实的模型服务。

- **必做部分约 35 分钟**。标 **〔可选〕** 的步骤时间够再做，不影响结论。
- 每一步写了三件事：**做** / **应看到** / **不对时看**。
- 发现问题时，记下步骤编号和时间，导出诊断（设置 → 诊断与关于 → 复制诊断信息），并截图。日志不含密钥。

**排查时看这些地方**

| 名称 | 位置 |
|---|---|
| 日志面板 | Auralink 里按 ⇧⌘L |
| 日志文件 | `~/Library/Logs/Auralink/auralink.log`（app）、`helper.log`（辅助进程：热键、AX、粘贴、URL） |
| 历史详情 | 每次会话的原文、结果、交付方式、服务和模型、各阶段耗时、命中的规则 |
| 系统设置 | 隐私与安全 → 辅助功能 / 麦克风 / 自动化 |

## 0. 准备（约 5 分钟）

**0.1 构建产物**
- 已经打好的版本：`~/code/Auralink/build/darwin-arm64/Auralink.app`。
- 要重打时，在 Linux 上执行：`MAC_DIR=code/Auralink scripts/mac.sh 'scripts/build-helper.sh && go tool mygo build'`。
- 包是 ad-hoc 签名，每次重打以后，macOS 都会忘掉授权。

**0.2 Key 文件**：`~/.config/auralink-dev/keys.env`。app 本身不读这个文件，它只给第 8 节的自动测试用；建好以后，下一步往 app 里填 Key 也从这里复制。

```sh
# 有哪个写哪个，没有的行删掉
DOUBAO_APP_ID=...
DOUBAO_ACCESS_TOKEN=...
DASHSCOPE_API_KEY=...      # 阿里云百炼
OPENAI_API_KEY=...
DEEPSEEK_API_KEY=...
```

执行一次 `chmod 600 ~/.config/auralink-dev/keys.env`，Mac 和 Linux 上各放一份。

**0.3 打开 app 并授权**
- **做**：
  1. 打开 `Auralink.app`。
  2. 进入设置（⌘,）→ 权限，授予辅助功能和麦克风。
  3. 如果系统设置里已经有一条旧的 Auralink 记录，而且它是打开的但不起作用，用 − 删掉，再重新添加。
- **应看到**：
  - 权限页的两项都显示已授权。
  - 侧边栏底部的状态显示辅助进程已就绪。
- **不对时看**：`helper.log`，以及设置 → 诊断与关于。

**0.4 配置模型服务**
- **做**：
  1. 打开模型服务页，加一个语音识别服务（豆包或阿里百炼，有哪个用哪个），再加一个 DeepSeek 语言模型。
  2. 把 Key 填进去，各点一次“测试连接”。
- **应看到**：
  - 两项测试都通过。
  - 转录页顶部不再提示“还没有设置语音识别服务”或“还没有配置语言模型”。
- **不对时看**：卡片上的错误文字、日志面板、设置 → 网络（代理）。

**0.5 其他准备**
- 打开设置 → 隐私 → **保存录音**（第 7 节要用）。
- 先把这些 App 打开备用：TextEdit、备忘录、Chrome、Safari、Arc、Slack（或微信）、VS Code（或 Cursor）。

## 1. 转录（约 8 分钟）

热键默认值：转录 fn，翻译 fn⇧，转写 fn⌃，粘贴最近结果 ⌃⌘V；都是点按触发。

**1.1 基本流程**
- **做**：
  1. 在 TextEdit 里点一下，先复制一段别的文字，用来检查剪贴板会不会恢复。
  2. 按 fn，说一句中英混合的话，例如“今天下午三点开会，讨论 Auralink 的发布计划”，再按 fn。
- **应看到**：
  - 浮窗出现在屏幕下方，不抢焦点，波形和计时在动，实时文字滚动。
  - 停止后浮窗依次显示“识别中…”“整理中…”，最后打勾。
  - 整理后的文字插在原来的光标处。
  - 按 ⌘V 粘出来的还是第 1 步复制的那段文字，说明剪贴板已经恢复。
- **不对时看**：
  - 浮窗没出现：`helper.log` 里有没有 hotkey 事件，权限页的辅助功能是否打开。
  - 没有插入：历史详情的“交付方式”。

**1.2 各种输入框**
- **做**：在备忘录、Slack、Chrome 网页里的 textarea、Chrome 里的富文本编辑器（Google Docs 或 Notion）里，各转录一次。
- **应看到**：每一处都直接插入，不会弹出答案卡片。contenteditable 的编辑器也一样。
- **不对时看**：历史详情的交付方式，和 `helper.log` 里 `textio.focus` 返回的 role。

**1.3 取消和停止**
- **做**：
  1. 录音时按 Esc。
  2. 再录一次，点浮窗上的“停止”。
  3. 再录一次，点浮窗上的 ×。
- **应看到**：
  - Esc 和 × 都会取消：什么都不插入，也不写历史。
  - “停止”和再按一次 fn 的效果一样。
- **不对时看**：日志面板。

**1.4 目标不能输入**
- **做**：把焦点放在访达的文件列表或桌面上，然后转录。在弹出的答案卡片上点“复制”，再点“插入”。
- **应看到**：
  - 结果进入答案卡片，卡片提示访达中没有可输入的位置。
  - 点卡片上的按钮时，焦点不会被抢到卡片上。
- **不对时看**：`helper.log` 的 focus 结果。

**1.5 中途切换 App**
- **做**：在 TextEdit 里开始录音，录音中切到备忘录，停止录音。然后切回 TextEdit，在卡片里点“插入”。
- **应看到**：
  - 结果进卡片，提示“TextEdit 已经不在前台”。
  - 切回 TextEdit 后点“插入”，文字插进 TextEdit。

**1.6 粘贴最近结果**
- **做**：按 ⌃⌘V。然后退出 Auralink（菜单栏 → 退出），重新打开，再按一次 ⌃⌘V。
- **应看到**：两次都粘出最近一次转录的结果。重启后的结果是从历史里读的。

**1.7 菜单栏**
- **做**：在 TextEdit 里点一下，然后点菜单栏图标 →“开始转录”，说一句话，再点“停止转录”。
- **应看到**：
  - 开始后，菜单项变成“停止转录”。
  - 文字插入 TextEdit，也就是点菜单之前在前台的 App。

**1.8 试一试**
- **做**：在转录页的“试一试”录一次。
- **应看到**：
  - 结果、原文和各阶段耗时都显示在页面里。
  - 不弹浮窗，也不写历史。

**1.9 〔可选〕右 ⌘ 长按**
- **做**：在转录页把快捷键改成“右 ⌘、长按”。按住右 ⌘ 说话，松开，然后把快捷键改回 fn 点按。
- **应看到**：按下就开始录音，松开就停止。真机的右 ⌘ 以前没有测过。

## 2. 翻译（约 6 分钟）

**2.1 选中文字的翻译**
- **做**：在 TextEdit 里选中一段英文，按 fn⇧。
- **应看到**：
  - 浮窗显示“正在翻译选中的文字…”和流式草稿。
  - 不录音：菜单栏不出现麦克风的橙点。
  - 译文替换选中的文字，剪贴板恢复。
- **不对时看**：`helper.log` 里 `textio.selection` 的结果（AX 读到的，还是 ⌘C 读到的）。

**2.2 网页上的选区：进卡片，在卡片里换语言**
- **做**：
  1. 在 Safari 的网页正文里选中一段文字，按 fn⇧。
  2. 在卡片右上角的“翻译成”里选“日语”。
  3. 在 Chrome 里重复一遍。
- **应看到**：
  - 网页上的文字不能编辑，所以译文流式显示在卡片里，不会粘到别处。
  - 换成日语后重新翻译，不录音。
  - **重点**：卡片是不激活的浮窗，看下拉菜单在里面能不能正常展开和选择。MyGo 的 Select 在这种窗口里还没有测过。
- **不对时看**：截图卡片；日志面板。

**2.3 其他 App 里的选区**
- **做**：在 Chrome 的 textarea、备忘录、Slack 里各选一段文字，做一次翻译。
- **应看到**：选中的文字能读到，并且被译文替换。

**2.4 编辑器：没有选区时不能把整行当成选区**
- **做**：在 VS Code 或 Cursor 里不选任何文字，按 fn⇧。再选中一段文字，按 fn⇧。
- **应看到**：
  - 没有选区时，直接开始录音，不会把光标所在的整行当成选区。这类编辑器不模拟 ⌘C。
  - 有选区时，AX 能读到选中的文字。
- **不对时看**：`helper.log` 的 selection。

**2.5 语音翻译**
- **做**：
  1. 不选文字，按 fn⇧，说一句中文，再按 fn⇧。
  2. 在翻译页打开“在卡片中显示结果”，再做一次。
  3. 把这个开关关回去。
- **应看到**：
  - 第一次：英文译文插入光标处。
  - 第二次：结果进卡片。

**2.6 〔可选〕读选区慢的 App**
- **做**：在微信里不选文字，按 fn⇧，按下以后马上开始说话。
- **应看到**：最多 1.5 秒后开始录音，开头说的话没有丢。

## 3. 转写（约 4 分钟）

**3.1 改写选中的文字**
- **做**：在 TextEdit（或邮件）里选中一段话，按 fn⌃，说“改得正式一点”，再按 fn⌃。
- **应看到**：浮窗显示“正在改写选中的文字…”，改写结果替换选区。

**3.2 按指令生成，再继续追问**
- **做**：
  1. 不选文字，按 fn⌃，说“写一段两百字的自我介绍”，再按 fn⌃。
  2. 卡片出现以后，再按 fn⌃，说“短一点”。
  3. 按 Esc 关闭卡片。
- **应看到**：
  - 回答超过 400 字时，流式输出过程中切到卡片，卡片显示标题和“按 fn ⌃ 继续追问”。如果回答没超过 400 字，就直接插入光标处，这时把指令改成“写一篇八百字的……”再试。
  - 继续追问后，卡片里的回答被替换。

## 4. 应用增强（约 8 分钟）

**4.1 没有自动化权限**
- **做**：打开系统设置 → 隐私与安全 → 自动化。
- **应看到**：
  - 列表里没有 Auralink。
  - 整个验证过程中，都不应该弹出“想要控制 Safari/Chrome”的对话框。

**4.2 按网址和浏览器匹配**
- **做**：
  1. 在应用增强页新建分组 A，网站规则写 `github.com`。
  2. 新建分组 B，成员选 Chrome，插入后按键选“无”。
  3. 在 Chrome、Safari、Arc 里，各开一个 github.com 标签和一个别的网站的标签。
  4. 在每个标签页面里的输入框（例如 github 的搜索框或评论框）按 fn，说一句话。
- **应看到**：
  - 浮窗的标签、历史详情的“规则”和网址，与当前标签一致：
    - github.com 的标签命中分组 A（显示“github.com · A”）；
    - Chrome 里别的网站命中分组 B（按浏览器）。
  - **请记下每种浏览器有没有读到网址**：
    - Safari 在前台时能不能读到，是重点；
    - Arc 分屏时，读到的是不是正在输入的那一边。
- **不对时看**：`helper.log` 里 `browser.url` 的 `via`（ax-focus / ax-document / ax-weburl / none）和耗时。

**4.3 预览和浏览器对话框**
- **做**：
  1. 回到 Auralink 的应用增强页，看顶部的预览，点“重新读取”。
  2. 点“把 github.com 加入 …”。
  3. 打开“浏览器…”对话框。
- **应看到**：
  - 预览显示上一个前台 App 和它的网址。
  - Safari 在后台时，预览显示“没有网址…”的说明。
  - 加入后，网站规则生效。
  - 浏览器对话框里，刚用过的浏览器标着“读到了网址”或“读不到网址：只能按应用匹配”。

**4.4 插入后按键**
- **做**：
  1. 新建分组“聊天”，成员选 Slack（或微信），插入后按键选 ↩。
  2. 在 Slack 的一个测试频道或自己的私信里转录一句话。
  3. 把焦点放在 Slack 里不能输入的地方再转录，在答案卡片上点“插入”。
- **应看到**：
  - 第 2 步：插入后自动发送。
  - 第 3 步：结果进卡片，点“插入”后不会自动发送。
- **不对时看**：历史详情的规则，以及 `helper.log` 的 paste 参数（press）。

**4.5 按键的作用范围**
- **做**：在“聊天”分组的“作用于”里勾上翻译。然后在 Slack 里依次做：
  1. 选中文字翻译；
  2. 不选文字，按 fn⌃ 说“写一句问候”；
  3. 选中文字，按 fn⌃ 改写。
- **应看到**：
  - 选中文字翻译：替换选区，不按 ↩。
  - 按指令生成：插入后按 ↩。
  - 改写选中的文字：替换选区，不按 ↩。

**4.6 添加应用对话框**
- **做**：在分组里打开“添加应用”，搜索，勾选一个 App；再手动填一个 Bundle ID。
- **应看到**：正在运行和已安装的 App 都列出来了，搜索可用，选中的 App 成为成员。

**4.7 总开关**
- **做**：关掉应用增强的总开关，在 Slack 里转录一句话。
- **应看到**：浮窗没有标签，插入后也不自动发送。做完把开关打开。

**4.8 〔可选〕更多浏览器**
- **做**：在 Edge、Brave（如果装了）里重复 4.2；在 Chrome 和 Arc 里各开两个窗口，切换窗口以后再试。
- **应看到**：读到的网址始终是正在输入的那个标签。

## 6. 出错时（约 4 分钟）

**6.1 语言模型出错**
- **做**：在模型服务页把 DeepSeek 的 Key 改错。
  1. 转录一次。
  2. 选中文字翻译一次。
  3. 把 Key 改对，在卡片上点“重试”。
- **应看到**：
  - 转录：照常插入，浮窗显示黄色的“已插入识别原文：语言模型出错了。”。
  - 翻译：卡片显示错误和“重试”。
  - 重试：直接成功，不用重新选中文字。

**6.2 语音识别服务出错**
- **做**：把语音识别服务的 Key 改错，转录一次。做完把 Key 改对。
- **应看到**：浮窗提示“语音识别失败：…”，并带“打开模型服务”按钮。

**6.3 去掉辅助功能**
- **做**：
  1. 在系统设置里把 Auralink 的辅助功能关掉，回到 Auralink 看转录页。
  2. 按 ⌃⌘V。
  3. 按 fn。
  4. 把辅助功能打开，不重启 app，再按 fn。
- **应看到**：
  - 第 1 步：转录页顶部出现授权提示。
  - 第 2 步：⌃⌘V 仍然可用（这时改用系统的全局快捷键）。
  - 第 3 步：fn 没反应。
  - 第 4 步：fn 恢复。
- **不对时看**：`helper.log` 里 event tap 的安装记录。如果 macOS 要求退出重开，照做后在这里记一笔。

- **应看到**：
  - 前面每一步的会话都有记录（Esc 和 × 取消的除外，“试一试”也没有记录）。
  - 详情里的原文、选中的文字、指令、目标语言、服务和模型、各阶段耗时、交付方式、规则都对。
  - 打开了“保存录音”的记录，可以“在访达中显示”录音。
  - 搜索能找到对应的记录。
